## How to add each one (10 minutes each)
1. Upwork, top menu **Find work**, then **Your project catalog** (or go to Profile, **Project catalog**, **Create a project**).
2. **Overview:** paste the title, choose category **Web Development > WordPress** (or the closest one shown), add the 5 search tags.
3. **Pricing:** turn on **3 tiers**. Paste each tier's name, description, delivery days, revisions and price. Tick the features listed.
4. **Gallery:** upload the matching PNG from this folder as the first image.
5. **Requirements:** paste the questions for the buyer.
6. **Description and FAQ:** paste them.
7. Click **Submit for review**. Upwork usually approves within a few days.
