## 4. What clients are hiring for right now (30 jobs)

Most frequent needs:
1. Elementor builds, redesigns and mobile responsiveness fixes
2. Page speed / performance optimization (caching, images, Cloudflare)
3. Bug fixes, site down, white screen, plugin conflicts
4. Malware cleanup and security hardening
5. SEO: technical, on page, and "AI SEO" (make sure ChatGPT, Claude and Perplexity can crawl)
6. Maintenance and on call support (hourly, as needed)
7. Migrations (hosting moves, Divi to block theme, WordPress to Squarespace)
8. Integrations: booking widgets, Stripe memberships, email automation (FluentCRM, Mailchimp, HubSpot forms)

Where the money is (biggest spending clients, $600K to $4.8M lifetime spend):
- Technical SEO + AI skills, long term, $25 to $40/hr
- Custom block theme developer, 750 page site, $20 to $90/hr
- Malware + security + custom code cleanup, $25 to $100/hr
- Elementor backend and plugin debugging, $15 to $30/hr

Warning signs seen: many $5 to $25 fixed price "full website" posts. Skip them. They hurt your earnings per hour and attract bad clients.
