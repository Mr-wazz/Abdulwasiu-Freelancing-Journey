# Adam O. Portfolio Website

Static site (HTML, CSS, JS). No build step. Design inspired by the layout style of dsquaredmedia.net, with original content and branding.

## Put it online free in 2 minutes (Netlify Drop)
1. Download the file `adam-portfolio-site.zip` and unzip it.
2. Open https://app.netlify.com/drop in your browser and sign up free (use Google).
3. Drag the unzipped `portfolio-site` folder onto the page.
4. Wait about 20 seconds. Netlify gives you a link like `random-name.netlify.app`.
5. Click **Site configuration** then **Change site name** and type something like `adam-wordpress`. Your link becomes `adam-wordpress.netlify.app`.
6. Send Claude the link so it goes in every proposal sign-off and on your Upwork profile.

## Update later
Edit the files, then drag the folder onto the **Deploys** tab of the same Netlify site.

## Files
- `index.html`: all page content
- `assets/styles.css`: design
- `assets/main.js`: menu, scroll effects, hero slideshow
- `assets/img/`: compressed screenshots (WebP) and share image
